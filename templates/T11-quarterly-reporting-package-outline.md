# T11 — Quarterly reporting package outline

## Purpose

The section-by-section outline of the package produced under SOP 24, with fillable blocks and the production checklist. One instance per client per quarter; the year-end instance adds the annual summary.

## How to use

- AA builds the package from this outline; CSA runs the production checklist; LA signs off before delivery.
- Keep the order. Clients learn where to find things; do not move sections between quarters.
- Blanks marked `______` are filled every quarter. Sections marked *if applicable* are omitted, not left empty.
