# T18 — Family balance sheet and income statement

## Purpose

The practice's own instrument for SOP 44: the balance-sheet statements every adult rates, the scoring sheet, the liabilities page, the income-statement forms, the budget-comparison worksheet and the transitions inventory.

## How to use

- CSA sends Part 1 to every adult with the invitation to family discovery (SOP 41) and with the annual-meeting pre-work; returns go to the AA only.
- AA scores in Part 2; LA writes Parts 3–6 narratives. The family sees averages and ranges, never individual scores.
- Rate honestly and quickly — first reactions are the useful ones. There are no right answers; the point is where we differ.

## Part 1 — The balance sheet statements (rate 1 = strongly disagree … 5 = strongly agree)

**Human capital — our people.** *The health, self-knowledge and freedom of each member to build a life that fits them.*

| # | Statement | 1–5 |
|---|---|---|
| H1 | Each adult in our family is in a position to do work that fits them, whether or not it pays. | |
| H2 | A member struggling with health, addiction or a setback gets the best help available, promptly. | |
| H3 | I feel free to choose where I live, what I do and whom I love without financial pressure from the family. | |
| H4 | Our children are growing up with a sense of who they are apart from the family's money. | |
| H5 | Members know how they could leave the family enterprise, and no one stays only because they cannot leave. | |
| H6 | Physical and emotional health are treated as family priorities, not private matters to hide. | |
| H7 | Each member has at least one relationship in the family in which they feel fully accepted. | |
| H8 | I can name what I am good at and what I want to build over the next ten years. | |

**Intellectual capital — what we know and can do.** *Knowledge suited to each member's role, and the habit of passing it on.*

| # | Statement | 1–5 |
|---|---|---|
| I1 | Every adult understands, at a level suited to them, how the family's wealth is held and governed. | |
| I2 | Members can read a financial statement or a trust report well enough to ask a useful question. | |
| I3 | What one member learns — in business, investing or life — reaches the others in a usable form. | |
| I4 | Rising-generation members are given real responsibility with real money, sized so mistakes are survivable. | |
| I5 | Each member has a mentor, inside or outside the family, for the thing they are trying to become good at. | |
| I6 | The family funds members' learning — courses, travel, apprenticeships — as readily as it funds portfolios. | |
| I7 | Members who work outside the family enterprise are valued for what they bring back. | |
| I8 | We know how each member learns best and present information to them accordingly. | |

**Social capital — our relationships.** *With each other, with newcomers, and with the communities we belong to.*

| # | Statement | 1–5 |
|---|---|---|
| S1 | Family members choose to spend time together when nothing requires it. | |
| S2 | Disagreements are aired and settled rather than avoided or fought through others. | |
| S3 | In-laws and newcomers are welcomed into the family's life and information, not kept at the edge. | |
| S4 | Members of different generations and branches know each other's lives, not just their names. | |
| S5 | The family makes decisions together in a way people accept even when they lose the argument. | |
| S6 | Members give time and money to their communities, and the family talks about it. | |
| S7 | When a member has a crisis, others show up. | |
| S8 | The cousins of the rising generation have relationships of their own with each other. | |

**Spiritual capital — our shared purpose.** *A reason for the family beyond preserving money; humility, gratitude and a long view.*

| # | Statement | 1–5 |
|---|---|---|
| P1 | The family can say, in its own words, what it is for beyond preserving money. | |
| P2 | Members tell the family's stories — including the failures — and the young know them. | |
| P3 | We recognize that our wealth came partly from luck and others' help, and act with that humility. | |
| P4 | Major decisions are weighed for their effect on grandchildren not yet born. | |
| P5 | Members express gratitude to those who came before and to those who serve the family now. | |
| P6 | The family's values are visible in how it gives, invests and treats the people who work for it. | |
| P7 | Our rituals mark the passages — births, comings of age, marriages, new elders, deaths. | |
| P8 | I feel part of something larger than my own household. | |

## Part 4 — Income statement inputs (each adult, annually, two weeks before the family meeting)

**A. Résumé update** (one page; what a good friend would know)
- What I did this year (work, study, projects, roles in the family): ______
- What I'm absorbed by now: ______
- Who I learned from this year, and what: ______
- A skill or responsibility I took on: ______
- Something I'd like the family to know: ______

**B. Personal mission statement** (one paragraph; revised or reaffirmed): ______

**C. Beneficiary self-report** (one per trust)

| Question | Yes / partly / no | Note |
|---|---|---|
| I understand what this trust is for and how it works. | | |
| I met the trustee this year and told them about my circumstances and plans. | | |
| I gave the trustee my honest view of how the relationship is working. | | |
| I improved my ability to read the trust's statements and reports. | | |
| I know how the trustee and other professionals are paid. | | |
| I could describe what I would do if the trust were distributed to me tomorrow. | | |

**D. Trustee report** (one per trust the family can influence; [Trust Co.] via SOP 46)

| Question | Yes / partly / no | Note |
|---|---|---|
| The trust's stated purposes guided this year's decisions. | | |
| I met each beneficiary at least once and learned about their situation. | | |
| A plan to grow each beneficiary's financial understanding is in place and working. | | |
| I told each beneficiary how they are doing in their role, and heard how I am doing in mine. | | |
| Investment, tax and legal policies were implemented and reviewed. | | |
| Distribution decisions were documented with reasons. | | |

**E. AA summary → LA narrative (one page):** roles taken on · mentoring formed · learning funded · trust relationships improved / deteriorated · liabilities resolved / new · *Did the family's people and knowledge grow this year?* ______
